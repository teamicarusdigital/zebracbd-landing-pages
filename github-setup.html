Setup Steps

1
Open a terminal and run gh auth login — select GitHub.com, then HTTPS, then authenticate via browser.
2
When prompted to choose an account, sign in as teamicarusdigital or a member of that org.
3
Confirm with gh auth status — you should see the org account listed as active.
4
Claude Code will automatically use this token for GitHub MCP tools (issues, PRs, repos).
Open GitHub Organization → Create Personal Access Token
